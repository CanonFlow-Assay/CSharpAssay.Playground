# Gilded Rose specimen

This specimen combines a pinned upstream production slice, a local build
harness, eight executable characterization cases, and an immutable reviewed
derivative. See `provenance.json` for exact origin and hashes and
`UPSTREAM_LICENSE.txt` for the upstream MIT license.

The derivative preserves the pinned implementation’s observed Conjured
behavior. The requested Conjured feature is intentionally deferred so the
refactor and business change remain independently reviewable.
